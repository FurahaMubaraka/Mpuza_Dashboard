## 🧭 Overview

This project focuses on building a **modern dashboard interface of MPUZA** that presents data in a clear, organized, and user-friendly way.  
The dashboard allows users to **monitor key metrics, view statistics, and interact with data visualizations** in real time.

The main objectives of this project are:
- Provide a clean and intuitive dashboard layout
- Display data using cards, icons,profiles
- Ensure responsiveness across devices
- Improve user experience through structured UI design
